# Guides

A guide here is a way of working that you read. It is not a skill: a skill is a folder an agent runs, with
instructions it follows and sometimes scripts. A guide is for a person (or an agent you point at it) who wants the
rules, the reasons and a checklist. More guides will join as they are ready.

| Guide | What it is for |
| --- | --- |
| [Writing your own gates](writing-gates.md) | Turning a mistake you keep fixing by hand into a check that runs by itself, and keeping that check honest. |
| [Documenting projects: docs as the system of record](documenting-projects.md) | Making the repository the record of decisions, so that nothing important lives only in a chat. |

Each guide opens with who it is for, gives numbered rules with the reason for each, and ends with a checklist. A line
that starts "What happened to me" is a real incident behind a rule.

To run something instead of reading it, see the [skills](../README.md#skills), for example crossfire, which
reviews a plan or a gate before you rely on it.
