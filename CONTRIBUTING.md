# Contributing

Thanks for taking an interest. Please read this first, because this repo works differently from most.

## How this repo is made

Everything here is generated from a private source and published as a copy. Nothing is edited in this repo
directly, so a change made here would be overwritten by the next publish.

## What helps

- **Issues are welcome.** A bug, a confusing passage in a skill, a case a skill handles badly, or an idea. Say which
  skill and version (the version is in `.claude-plugin/marketplace.json`), what you did, what you expected, and
  what happened.
- **Pull requests are read as proposals.** Open one if showing the change is the clearest way to explain it. I read
  it and re-make the change at the source. It ships in a later update, and I credit you in the pull request that
  brings it here. Your pull request is then closed, because its commit is not the one that ships.

## Before you open a pull request

- Keep it small and about one thing.
- Skills are prose and a few scripts. If you change a script, say how you ran it.
- Do not include secrets, personal paths, or anything private in an issue, a pull request or its examples.

## Security problems

Do not open an issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).

## Conduct

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
